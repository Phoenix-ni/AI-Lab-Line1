# Git命令学习笔记
## 一、命令
1.初始化本地库
```
git init
```
2.查看本地库状态
```
git status
```
3.添加暂存区
```
git add 文件名
```
删除暂存区文件
```
git rm --cached 文件名
```
4.提交本地库
```
git commit -m "日志信息" 
```
- 先添加暂存区，后提交。

![alt text](<屏幕截图 2026-11-04 211343-1.png>)

5.查看日志信息
```
git reflog
```
查看详细日志信息(详细版本号+Anthor+Date)
```
git log
```
![alt text](<屏幕截图 2026-11-04 212225.png>)

- --oneline：每一条提交压缩成一行

-  --graph：画出 ASCII 线条，把分叉、合并可视化

-  --decorate：标注分支名字

-  --all：显示仓库全部分支

6.版本穿梭	
```
git reset --hard 版本号	
```
## 二、分支
1、查看分支 
```
git branch -v
```
2、创建分支
```
git branch 分支名	
```
3.切换分支
```
git checkout 分支名
```
![alt text](<屏幕截图 2026-11-04 202253.png>)

4.合并分支
```
git merge 分支名（被合并的分支）
```
![alt text](<屏幕截图 2026-11-04 211849-1.png>)

5.冲突
- 合并冲突时，两个分支在同一个文件的同一个位置有两条完全不同的修改，Git无法决定使用哪个，从而发生冲突，需要手动合并。
```
<<<<HEAD
  当前分支内容
=============
  被合并分支内容
>>>>被合并分支名
```
- 解决冲突：将不要的删去——保存后将其添加至暂存区——git commit -m "日志信息"    （不加文件名）
## 三、Github_Git
- 远程仓库操作：

1.创建远程仓库别名
```
git remote -v   （查看当前所有远程地址别名）
git remote add 别名 远程地址
```
2.推送本地分支到远程仓库
```
git push 别名 分支名
```
3.拉取远程库到本地库
```
git pull 别名 分支名
```
4.克隆远程仓库到本地
```
git clone 远程仓库
```
