## 四、规范语义的 Commit
固定格式：
```
类型：简短描述
```
-  feat ：新增功能、新增内容

-  fix ：修复 bug / 改错

-  docs ：文档修改

-  style ：格式调整，不改动内容（空格、换行、标点）

-  refactor ：重构，换一种写法，不是新增功能，也不是修 bug

-  perf ：性能优化

-  test ：新增、修改测试代码

-  chore ：构建、工程杂项，比如改依赖、脚本
